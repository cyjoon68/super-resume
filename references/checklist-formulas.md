# 이력서 체크리스트와 문장 구성

## 확인 항목
첫 화면: 가장 강한 경험이 상단에 위치하는지, 공고 기술이 보이는지, 상태(재직/퇴사/신입)가 식별되는지.
프로젝트: 기간과 역할이 명시됐는지, 기능 나열이 아닌 문제 해결 위주인지, 수치나 측정 지표가 포함됐는지.
자소서: 500자 내외로 구분되고 각 단락에 요약 제목이 있는지.

## 문장 구성 패턴
프로젝트 설명: [도메인/기능] + [문제/병목] + [해결 방법] + [측정 결과].
지원동기: [공고 요구사항] + [내 경험 연결] + [입사 후 기여].
자소서 소제목: [내 역량/프로젝트]로 [회사 요구사항]에 기여.

이 패턴은 검토자가 정보를 빠르게 파악할 수 있도록 돕는 형식이다.
