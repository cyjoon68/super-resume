# 포트폴리오 구성

## 이력서와의 관계
포트폴리오는 이력서에서 한 줄로 정리한 문제 해결을 그림과 함께 펼쳐서 보여준다. 개인정보나 기술 스택을 반복하지 않는다.

## 문제 해결 섹션 구조
제목: 한 줄 요약 (Google XYZ — X를 달성했고, Y 수치로 측정, Z 방법으로)
시각 자료: 아키텍처/데이터 플로우/시퀀스 다이어그램
문제: 2~3줄 — 증상과 영향
진단: 병목을 찾은 과정 — 관찰, 측정 도구와 지표, 가설, 원인 확정. 생각의 흐름이 순서대로 드러나야 하며 바로 답을 쓰지 않는다
해결: 2~3줄 — 선택한 원리와 대안 비교·고민
결과: 2~3줄 — XYZ 형식의 측정 수치

시각 자료는 기능 캡처보다 구조도나 데이터 흐름도가 더 효과적이다. 개수는 3~5개 내외.
